# Support

SubtitleOps is community-supported open-source software. There is no commercial support contract or guaranteed response time.

## Where to ask

- **Bug:** use the bug report issue form with a minimized, redistributable subtitle sample.
- **Feature or format request:** use the feature request form and describe the publishing workflow or interoperability requirement.
- **Adoption report:** use the adoption report form to share a public integration, approximate scale, and feedback.
- **Security:** follow [SECURITY.md](SECURITY.md). Do not disclose exploit details in a public issue.

## Supported versions

Before 1.0, fixes target the latest released minor version and `main`. Older pre-1.0 lines may not receive backports. Security exceptions are decided case by case based on severity and release impact.

## Useful reproduction details

Include:

- `subtitleops --version`;
- operating system and Python version;
- the exact command and configuration;
- expected and observed output;
- the smallest subtitle file that reproduces the problem;
- whether the input contains private, identifying, licensed, or confidential material.

Remove unrelated dialogue and metadata before posting. A synthetic sample with the same structure is preferred.

## Maintenance targets

The maintainer aims to acknowledge actionable reports within seven days and triage ordinary issues or pull requests within fourteen days. These are best-effort targets, not an SLA.
