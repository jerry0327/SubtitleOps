# Code of Conduct

SubtitleOps project spaces are for technical collaboration.

Participants are expected to:

- discuss ideas and behavior rather than attacking people;
- provide reproducible, specific feedback where possible;
- respect different levels of experience and different backgrounds;
- avoid harassment, discrimination, threats, doxxing, or deliberately disruptive behavior.

Maintainers may edit or remove content, close threads, or restrict participation when behavior materially interferes with productive collaboration.

If you need to report conduct privately, use an appropriate private contact channel made available by the repository owner rather than escalating personal details in a public issue.
